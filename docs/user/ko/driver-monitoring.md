# 운전자 모니터링

Carrot Web의 차량·하드웨어 > 운전자 모니터링에서 `DisableDM`을 설정합니다. 기본값은 `0`이며 변경 뒤 기기를 재부팅해야 적용됩니다.

| 값 | 동작 |
|---|---|
| `0` | 기존 운전자 카메라 모델과 감시를 사용합니다. |
| `1` | 운전자 감시를 끕니다. 웹 도로 영상은 켜지지 않습니다. |
| `2` | 운전자 감시를 끄고 웹 도로 영상(WebRTC)을 허용합니다. `ClusterHud`가 켜져 있으면 웹 영상은 사용할 수 없습니다. |

`DisableDM`은 파일 백업, QR 백업과 설정 프로필에 포함되고 복원됩니다. 저장값을 다른 DM 설정으로 이행하거나, CANCEL 세 번으로 시동 구간 감시를 바꾸는 기능은 없습니다. 영상 설정만 바꾼다고 운전자 감시가 독립적으로 켜지지는 않습니다.

Driver View와 AlwaysOnDM은 기존 동작을 사용합니다. 카메라 장애는 별도의 조작 감시로 자동 전환하지 않습니다. 운전자 경고음은 기존 음량 설정을 따릅니다.

운전자 감시를 끄면 기존 감시 경고와 감속·재사용 제한의 보호를 사용할 수 없습니다. 실제 차량의 감시·경고·영상 동작은 현장 검증이 필요합니다. 웹 영상 사용은 [웹당근 안내](carrot-web.md)를 참고하세요.
